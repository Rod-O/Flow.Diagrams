# Flow.Diagrams API

The reference for every public type of Flow.Diagrams, generated from the source.

- <xref:Flow.Diagrams.Core.Diagram>: the model — nodes, ports, links and groups, with routers, behaviors and options
  around it (`Flow.Diagrams.Core`).
- <xref:Flow.Diagrams.BlazorDiagram> and <xref:Flow.Diagrams.Components.DiagramCanvas>: the Blazor side that draws
  it, and <xref:Flow.Diagrams.Export.DiagramSvgExporter> for SVG export (`Flow.Diagrams`).

For how to use them, see the [guides and live examples](https://rod-o.github.io/Flow.Diagrams/).
